# 旅行推銷員問題（TSP）五種方法實作

## 簡介

旅行推銷員問題（Traveling Salesperson Problem, TSP）是組合最佳化中的經典問題。目標是：給定一組城市及其之間的距離，找出一條最短可能路線，讓推銷員能夠造訪每個城市恰好一次，最後再回到起始城市。

本資料夾以 Python 實作五種常用的求解方式，並使用相同的 7 個城市座標進行比較，便於觀察各演算法的特性與表現。

## 城市座標（範例）

所有程式皆使用以下座標作為測試資料：

| 城市編號 | 座標 (x, y) |
|---|---|
| 0 | (0, 0) |
| 1 | (1, 2) |
| 2 | (3, 1) |
| 3 | (6, 2) |
| 4 | (7, 0) |
| 5 | (5, -2) |
| 6 | (2, -1) |

距離計算方式採用歐幾里得距離（`math.hypot`）。

## 演算法原理與比較

| 演算法 | 類型 | 初始解 | 搜尋策略 | 優點 | 缺點 |
|---|---|---|---|---|---|
| **貪婪演算法（Nearest Neighbor）** | 建構式（Constructive） | 從起始點開始逐步建構 | 每次選擇「最近」的未訪問城市 | 實作最簡單、速度最快，能快速得到一個可行解 | 極易陷入局部最優，對起點及選擇順序非常敏感 |
| **爬山演算法（Hill Climbing）** | 局部搜尋（Local Search） | 隨機產生路線 | 以 2-opt 產生鄰域解，只接受改善解（距離更短） | 比純貪婪更容易找到較好解，概念簡單易懂 | 僅能往下坡（改善）走，無法跳脫局部最優，搜尋結束於平坦或局部極小點 |
| **模擬退火法（Simulated Annealing）** | 機率式局部搜尋（Metaheuristic） | 隨機產生路線 | 使用交換（swap）鄰域，初期以高機率接受較差解，隨溫度下降逐漸只接受改善解 | 能跳脫局部最優，在中小型 TSP 中表現較穩定，實作也不算複雜 | 需調整初始溫度、降溫率等參數，收斂時間較爬山長 |
| **梯度下降法（離散近似）** | 局部搜尋（近似實作） | 隨機產生路線 | 每次採樣鄰域，選擇「最陡下降」方向（最大改善）的移動並執行，無改善達一定次數則早停 | 模擬連續最佳化中「梯度下降」的思路，較爬山更具方向性地搜尋 | TSP 並無真正的連續梯度，本實作為離散近似，仍可能陷入局部最優 |
| **改良法（2-opt 改良）** | 混合式（建構 + 局部改良） | 貪婪演算法（Nearest Neighbor）取得初始解 | 對初始解反覆執行 2-opt 交換，直到找不到任何改善為止（First/Best 改善） | 結合建構式與局部搜尋的優點，通常比單純貪婪好很多，且實用且常用於 TSP 入門 | 仍屬局部搜尋，若初始解很差也可能收斂到品質一般的局部最優 |

## 檔案說明

| 檔案 | 演算法 | 說明 |
|---|---|---|
| `01_greedy_nearest_neighbor.py` | 貪婪演算法（Nearest Neighbor） | 從起始城市開始，每次選擇最近未訪問的城市，最後回到起點。簡單快速但易陷入局部最優。 |
| `02_hill_climbing.py` | 爬山演算法（Hill Climbing） | 從隨機路線出發，使用 2-opt 鄰域產生鄰近解，若更好則接受，否則捨棄，只接受上坡（改善）移動。 |
| `03_simulated_annealing.py` | 模擬退火法（Simulated Annealing） | 類似爬山但允許以一定機率接受較差解（依溫度與 `exp(-ΔE/T)` 決定），可跳出局部最優並逐漸降溫收斂。 |
| `04_gradient_descent_tsp.py` | 梯度下降法（Gradient Descent，離散近似） | 由於 TSP 為離散組合問題，此處以「最陡下降」概念實作：每次從鄰域中找出最佳改善移動並採用，搭配早停機制。 |
| `05_improved_2opt.py` | 改良法（2-opt 改良法） | 先以貪婪演算法（Nearest Neighbor）取得初始解，再反覆使用 2-opt 交換進行局部改良，直到無法再改善為止。 |

## 使用方式

各程式皆可直接執行（使用內建範例座標）：

```bash
python 01_greedy_nearest_neighbor.py
python 02_hill_climbing.py
python 03_simulated_annealing.py
python 04_gradient_descent_tsp.py
python 05_improved_2opt.py
```

## 實作細節

- **鄰域操作**：`02`、`04` 主要使用 `2-opt` 交換；`03` 使用 `swap`（兩點交換）。
- **距離矩陣**：預先計算所有城市兩兩間的歐幾里得距離，避免重複計算。
- **路線表示**：以城市編號串列表示路線，計算總距離時會加上最後一個城市回到第一個城市的距離。
- **隨機性**：`02`、`03`、`04` 使用隨機初始解與隨機鄰域搜尋，`01`、`05` 則較具決定性。
- **收斂控制**：`04` 設有 `patience` 早停；`03` 設有溫度下限與降溫率。

## 注意事項

- 所有程式皆使用相同的 7 個城市座標範例，方便比較各方法結果。
- `04_gradient_descent_tsp.py` 為 TSP 在離散空間的近似實作，並非連續函數的真正梯度計算。
- 結果會因隨機種子與參數而有所不同，可調整參數以獲得較佳解。
- 若要測試其他城市配置，只需修改各程式中的 `CITIES` 清單即可。

## 延伸學習建議

- 嘗試調整 `random.seed()` 或移除種子，觀察不同執行結果的差異。
- 比較各方法在相同條件下的總距離，找出對此範例最合適的演算法。
- 嘗試實作 `3-opt`、`Or-opt` 或加入多次重啟（Random Restart）來提升解的品質。
- 嘗試改用真實地圖座標或更多城市數量，觀察各演算法的擴展性與效能差異。
