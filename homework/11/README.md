# 數值微分與數值積分（含蒙地卡羅法、n 變數推廣）

> **AI 使用聲明：本作業有使用 AI。** 程式碼與本 README 由 opencode（AI）協助撰寫、檢查與說明；題目理解、參數選擇與結果解讀由學生確認。

本資料夾以 Python 3 實作：

1. 單變數數值微分（前向、後向、中心有限差分）。
2. 單變數數值積分（黎曼中點法）。
3. 單變數蒙地卡羅積分。
4. n 變數數值微分（梯度）與 n 變數數值積分（超體積）。
5. n 變數蒙地卡羅積分。
6. `integral(f, low, high)`：以黎曼積分法計算 n 變數積分，`n` 由 `low`、`high` 陣列的長度決定。
7. 分別以 1 維、2 維、5 維、100 維計算 `f(x) = x1^2 + ... + xn^2`，`low = 0`、`high = 1`。

全部只使用 Python 標準函式庫，不需安裝任何套件。

## 1. 方法說明

### 1.1 單變數數值微分：有限差分

給定步長 `h`，三種常見近似：

| 方法 | 公式 | 截斷誤差 |
|---|---|---|
| 前向差分 | `(f(x+h) - f(x)) / h` | `O(h)` |
| 後向差分 | `(f(x) - f(x-h)) / h` | `O(h)` |
| 中心差分 | `(f(x+h) - f(x-h)) / (2h)` | `O(h^2)` |

中心差分誤差最小，但 `h` 不是越小越好：`h` 太小會讓 `f(x+h) - f(x-h)` 的浮點數舍入誤差被除以很小的 `h` 放大。程式以 `h = 1e-5` 作為預設值，並列出不同 `h` 的影響。

### 1.2 n 變數數值微分：梯度

對每一維 `i` 分別做中心差分：

```text
∂f/∂x_i ≈ (f(x + h·e_i) - f(x - h·e_i)) / (2h)
```

其中 `e_i` 是第 `i` 維的單位向量。需要 `2n` 次函數呼叫。

以 `f(x) = Σ xi^2` 為例，解析梯度為 `∇f = (2x1, 2x2, ..., 2xn)`；在 `x = (1,...,1)` 時每一維都應為 2。

### 1.3 黎曼中點法（一維）

把 `[a, b]` 切成 `steps` 等份，每份寬度 `Δx = (b-a)/steps`，取中點高度：

```text
∫[a,b] f(x) dx ≈ Δx · Σ f(a + (i + 1/2)Δx)
```

### 1.4 黎曼中點法（n 變數，超體積）

令 `low = (l1,...,ln)`、`high = (h1,...,hn)`，每一維切 `steps` 段，共 `steps^n` 個格點：

```text
∫ f(x) dx ≈ (V / steps^n) · Σ f(m)
```

- `m` 走遍所有格點的中點。
- `V = Π (hi - li)` 是超長方體體積。
- 本程式以 `itertools.product` 展開格點，`integral(f, low, high, steps=8)` 可直接呼叫；`steps` 有預設值，所以 `integral(f, low, high)` 也能用。

本題 `f(x) = Σ xi^2`、`low = 0`、`high = 1` 的解析解為：

```text
∫[0,1]^n Σ xi^2 dx = n · ∫[0,1] x^2 dx = n/3
```

### 1.5 蒙地卡羅積分

在超長方體內均勻取 `N` 個隨機樣本 `x_k`：

```text
∫ f(x) dx ≈ V · (1/N) · Σ f(x_k)
```

估計值的標準誤差可用樣本變異數估計：

```text
SE ≈ V · sqrt( ( (1/N)Σf(x_k)^2 - mean^2 ) / N )
```

蒙地卡羅收斂速度為 `O(1/sqrt(N))`，**與維度無關**；黎曼法的格點數是 `steps^n`，會隨維度指數成長。

### 1.6 維度災難

| 維度 n | steps=2 的格點數 |
|---:|---:|
| 1 | 2 |
| 2 | 4 |
| 5 | 32 |
| 10 | 1,024 |
| 100 | 2^100 ≈ 1.27 × 10^30 |

即使每秒能算 10 億個格點，`2^100` 個點也需要約 `4 × 10^13` 年。因此程式設定 `MAX_GRID_POINTS = 2_000_000` 保護機制：格點數超標時直接擲出錯誤並提示改用蒙地卡羅法。100 維的黎曼示範只能取最粗的 `steps = 1`（只有一個中點），結果自然不準確。

## 4. 結果討論

- **微分**：中心差分明顯比前向／後向準確；`h` 過小時舍入誤差反而變大，所以預設 `h = 1e-5` 是較好的折衷。梯度在各維度都接近解析值 2，誤差隨 `n` 略增但仍很小。
- **低維度**：黎曼法非常準。1 維 10000 段誤差只有 `8.33e-10`；2 維 300 段（9 萬點）誤差 `1.85e-06`；5 維 10 段（10 萬點）誤差 `4.17e-03`。
- **100 維黎曼**：即使每維只切 1 段，中點法得到 `100 × 0.5^2 = 25`，離解析值 33.33 很遠；想提高精度就必須用到 `2^100` 個格點，完全不可能。這正是維度災難。
- **蒙地卡羅**：同樣 10 萬個樣本，1 維到 100 維的標準誤差都大約在 `1e-3 ~ 1e-2`，100 維估計值 33.3071 與解析值 33.3333 的差距只有 0.026，落在約 2.8 個標準誤差內。收斂速度不受維度影響，是高維積分的首選。
- **取捨**：一維時黎曼法又快又準；維度一高，蒙地卡羅幾乎是唯一可行的方法。若要再提升蒙地卡羅精度，可增加樣本數、使用重要性取樣（importance sampling）或準蒙地卡羅（低差異序列）。
