# Homework 3：列舉＋暴力 — 列舉真值表求解 SAT 問題

本專案使用 opencode 及 gemini 製作。

本專案實作一個「暴力列舉真值表」的 SAT 求解器，系統性地把 $2^n$ 種變數指派全部列出來，逐一驗證布林公式是否為真，找出所有滿足指派。

---

## 實作方法說明

任何 n 個布林變數的公式，其真值表只有 $2^n$ 列。暴力法就是照單全收、全部檢查：

1. **列舉**：把整數 `0..2^n-1` 當成一個 n 位元計數器，第 i 位元就是變數 $x_i$ 的值。
   ```python
   for code in range(2**n):
       truth = [((code >> v) & 1) == 1 for v in range(n)]
   ```
2. **驗證**：對每組 `truth` 代入公式，若全部子句為真即為一組解答。
3. **收集**：把所有解答收集起來輸出；若一組都沒有，代表此公式不可滿足（UNSAT）。

### 資料結構（CNF 合取範式）

| 物件 | 表示法 | 範例 |
| :--- | :--- | :--- |
| 變數 | 數字 `0..n-1` | `x0, x1, x2` |
| 文字 literal | `(var, neg)` tuple，`neg=False` 為正、`True` 為負 | `(0, True)` 代表 `~x0` |
| 子句 clause | 文字的 list（OR） | `[(0, False), (1, True)]` = `x0 ∨ ~x1` |
| 公式 formula | 子句的 list（AND） | 全部子句 AND |

---

## 測試案例與結果

| 案例 | 公式 | 結果 |
| :--- | :--- | :--- |
| 1 | `(x0∨x1) ∧ (~x0∨~x1)` | 有解，2 組：`x0=1,x1=0`；`x0=0,x1=1`（即 XOR） |
| 2 | `(x0∨x1) ∧ (~x0∨x1) ∧ (x0∨~x1)` | 有解，1 組：`x0=1,x1=1` |
| 3 | 四個子句涵蓋所有組合 | **無解（UNSAT）**，恆假 |
| 4 | 每子句同時含 `x` 與 `~x` | 恆真（tautology），全部 8 組皆解 |

---

## 複雜度分析

* **時間複雜度**：$O(2^n \times m)$，其中 $m$ 為公式總文字數。
* **空間複雜度**：$O(n)$（每組指派暫存，不計收集解答的空間）。

列舉法是最簡單、保證正確的 SAT 求解方式，但 $n$ 每增加 1，計算量就加倍，故僅適用於變數極少（$n \le 20$ 左右）的場合，這也正是 SAT 是 NP-complete 問題的具體展現。
