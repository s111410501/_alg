# Homework 3：列舉＋暴力 — 列舉真值表求解 SAT

本作業使用 opencode 及 gemini 製作。

這份程式碼使用「暴力窮舉（Brute Force）」的方式來解 **SAT（布林可滿足性問題）**。主要概念是：給定 $n$ 個布林變數，總共只有 $2^n$ 種可能的 `True / False` 組合，程式透過「二進位計數器」將每一組全部列出來，並代入公式檢查，找出所有能讓公式成立的解答。

---

## 一、程式架構

程式主要分成四個部分：**資料表示、邏輯計算、組合列舉、輸出呈現**。

### 1. 資料結構（CNF 格式）

程式用 Python 的 `list` 與 `tuple` 來表示**合取範式（CNF）**：

| 物件 | 表示法 | 範例 |
| :--- | :--- | :--- |
| 變數 | 用整數編號 | `0` 代表 $x_0$、`1` 代表 $x_1$ |
| 文字 Literal | `(變數, 是否有 NOT)`，tuple | `(0, False)` 代表 $x_0$；`(0, True)` 代表 $\sim x_0$ |
| 子句 Clause | 多個文字組成的 list（彼此 **OR**） | 其中一個為真即成立 |
| 公式 Formula | 多個子句組成的 list（彼此 **AND**） | 所有子句都為真才成立 |

### 2. 邏輯計算函式

由小到大逐層判斷布林值：

```python
def eval_literal(lit, truth):   # 單一文字的值（含 NOT 反轉）
def eval_clause(clause, truth)  # 用 any() 檢查子句內是否有任一文字為真
def eval_formula(formula, truth) # 用 all() 檢查是否每個子句都為真
```

### 3. 列舉所有組合（`truth_table`）

程式利用整數的**二進位位元**來代表每個變數的值：

* 迴圈跑 `range(2**n)`，`code` 從 $0$ 數到 $2^n - 1$。
* 透過位元運算 `(code >> v) & 1` 抓出第 `v` 個位元是 0 還是 1，轉成對應的 `True / False`。
* 只要該組指派能讓 `eval_formula` 回傳 `True`，就加入解答清單。

### 4. 輸出與印出（`print_table` 與 `show`）

* `print_table(n, formula)`：排版印出完整的**真值表**，顯示每個變數值、每個子句的運算結果（C0, C1, …）以及最終公式的 SAT 判定。
* `show(n, formula)`：呼叫 `print_table` 印出表格，並統計回傳有幾組滿足解（或顯示無解）。

## 二、測試案例

程式在 `__main__` 中測試了 4 種經典情況：

| 案例 | 公式 | 結果 |
| :--- | :--- | :--- |
| 1（XOR） | `(x0∨x1) ∧ (~x0∨~x1)` | 只有在兩變數值不同時成立，找到 **2 組解**（`x0=1,x1=0` 與 `x0=0,x1=1`） |
| 2（單一解） | `(x0∨x1) ∧ (~x0∨x1) ∧ (x0∨~x1)` | 限制較多，只有 **1 組解**（`x0=1,x1=1`） |
| 3（矛盾式） | 四個子句分別排除一種組合 | **無解（UNSAT）**，沒有任何指派能滿足 |
| 4（恆真式） | 每個子句都同時含 `x` 與 `~x` | 恆真（tautology），全部 $2^3 = 8$ 組指派皆為解 |
