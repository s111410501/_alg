# 迭代法（Iteration）

一種透過「重複執行同一個計算步驟，不斷修正結果」來逐步逼近答案的解題方法。

## 1. 簡介

**迭代法（Iteration）** 是指從一個初始猜測值開始，以上一次的計算結果作為下一次的輸入，重複套用固定的計算公式，不斷更新數值，逐步逼近問題的正確解。

與直接求出精確解不同，迭代法採用的是「**一步步逼近**」的思路：不求一步到位，而是透過持續修正來取得滿足精度要求的近似解。

## 2. 核心概念

迭代法可以用以下公式表示：

$$
x_{n+1} = g(x_n), \quad n = 0, 1, 2, \ldots
$$

- **$x_0$** — 初始值（Initial Value）：迭代的起始猜測值。
- **$g(x)$** — 迭代函式（Iteration Function）：定義如何從舊值產生新值的規則。
- **$x_n$** — 第 $n$ 次迭代的近似值。
- **$x_{n+1}$** — 第 $n+1$ 次迭代的近似值（由 $x_n$ 計算而得）。

當序列 $x_0, x_1, x_2, ...$ 隨著迭代次數增加而趨近於某個固定值 $x^*$，即

$$
\lim_{n \to \infty} x_n = x^*
$$

就稱為**收斂（Convergence）**，此時 $x^*$ 即為問題的近似解。

## 3. 運作流程

迭代法的基本流程如下：

1. **設定初始值**：選擇一個合適的 $x_0$ 作為起點。
2. **套用迭代公式**：利用 $x_{n+1} = g(x_n)$ 計算新值。
3. **檢查停止條件**：判斷當前結果是否已達到所需的精度。
4. **決定繼續或停止**：若尚未達到精度，將 $x_{n+1}$ 設為 $x_n$ 並重複步驟 2；若已達到精度或超過最大迭代次數，則停止並回傳結果。

### 3.1 偽程式碼

```text
輸入：初始值 x0、迭代函式 g(x)、誤差容限 ε、最大迭代次數 M

x ← x0
n ← 0

重複：
  x_new ← g(x)
  
  若 |x_new - x| < ε 或 |f(x_new)| < ε：
      回傳 x_new（已收斂）
  
  x ← x_new
  n ← n + 1
  
  若 n >= M：
      回傳 x（達到最大迭代次數，停止）
```

## 4. 範例：用希羅法求 $\sqrt{2}$

我們想要求 $\sqrt{2}$（即解 $x^2 = 2$），可以使用**希羅法（Heron's Method）**，其迭代公式為：

$$
x_{n+1} = \frac{x_n + \frac{2}{x_n}}{2}
$$

以 $x_0 = 1.0$ 作為初始值：

| 迭代次數 ($n$) | $x_n$ | 備註 |
|---|---|---|
| $0$ | $1.0$ | 初始值 |
| $1$ | $1.5$ | 第一次迭代 |
| $2$ | $\approx 1.4166667$ | 第二次迭代 |
| $3$ | $\approx 1.4142157$ | 第三次迭代 |
| $4$ | $\approx 1.4142136$ | 第四次迭代 |

真值 $\sqrt{2} \approx 1.41421356$。可以看出，隨著迭代次數增加，近似值會越來越接近正確答案。

## 5. 迭代法 vs. 遞迴法

雖然兩者都會「重複執行」，但運作方式不同：

| 比較項目 | 迭代法（Iteration） | 遞迴法（Recursion） |
|---|---|---|
| **執行方式** | 使用**迴圈**（`for`、`while`）重複執行 | 函式**呼叫自己**來重複處理 |
| **狀態更新** | 直接更新變數（$x \leftarrow g(x)$） | 透過函式參數與回傳值逐層運算 |
| **記憶體使用** | 固定空間，較省記憶體 | 需要使用呼叫堆疊（Call Stack），深度過大可能導致堆疊溢位 |
| **邏輯表達** | 強調「重複步驟」的流程 | 強調「問題分解」的結構 |
| **典型範例** | 數值逼近、疊代計算 | 樹狀結構、分治法、回溯法 |

## 6. 常見應用

迭代法廣泛應用於需要逐步逼近的計算問題：

- **求方程式根** — 牛頓法（Newton–Raphson Method）、固定點迭代法（Fixed-Point Iteration）
- **解線性方程組** — 雅可比法（Jacobi Method）、高斯–賽德爾法（Gauss–Seidel Method）
- **最佳化** — 梯度下降法（Gradient Descent）
- **機器學習** — K-Means 分群演算法、EM 演算法（Expectation–Maximization）
- **數值計算** — 各類需逼近解的工程與科學計算問題

## 7. 重要名詞說明

| 名詞 | 說明 |
|---|---|
| **初始值（Initial Value）** | 迭代的起點。選擇合適的初始值有助於加快收斂，選擇不當則可能導致發散。 |
| **收斂（Convergence）** | 迭代結果隨著次數增加而逐漸趨近於正確解。 |
| **發散（Divergence）** | 迭代結果隨著次數增加而遠離正確解，無法逼近答案。 |
| **停止條件（Stopping Criterion）** | 決定何時結束迭代的依據。常見方式：誤差容限 $\varepsilon$（如 $|x_{n+1}-x_n| < \varepsilon$）、函式值接近 0（$|f(x_{n+1})| < \varepsilon$），或是設定**最大迭代次數**作為安全機制。 |
| **精度（Tolerance）** | 允許的誤差範圍，用來控制答案的精確程度。 |

## 8. 總結

**迭代法的核心原則：用舊值算出新值，反覆套用，逐步逼近。**

簡單來說，就是「**重複 → 更新 → 逼近 → 停止**」。它的優勢在於邏輯清晰、容易實作，特別適合那些無法一步求解、但能透過重複修正逐步得到近似解的問題。
